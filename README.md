# Guardianes de la Chacra

Tower defense andino hecho con Flutter y Flame: plagas y espíritus del mal clima bajan de las montañas para devorar la cosecha de la collca, y el jugador coloca guardianes para detenerlos.

El contexto del proyecto y las decisiones de arquitectura están en [CLAUDE.md](CLAUDE.md).

## Ejecutar

```powershell
flutter pub get
flutter run -d chrome
```

## Calidad

```powershell
flutter analyze
flutter test
```
